# 홍보 영상 만들기

X(x.com)에 올릴 허브트레이스 소개 영상을 앱 화면에서 바로 녹화합니다. 결과물은 `promo/out/`에 생기고 용량이 커서 커밋하지 않습니다.

| 파일 | 길이 | 용도 |
|---|---|---|
| `out/hubtrace-promo.mp4` | 5분 4초 | 본편(배경음 포함). X Premium 계정은 그대로 올릴 수 있습니다 |
| `out/hubtrace-promo-silent.mp4` | 5분 4초 | 본편 무음(다른 음악을 입힐 때) |
| `out/hubtrace-teaser.mp4` | 2분 11초 | 줄임본. X 일반 계정 업로드 한도(2분 20초) 안 |
| `out/hubtrace-poster.jpg` | | 제목 장면 이미지 |

형식: 1920×1080, 30fps, H.264(High), AAC 192kbps, `faststart`. X 권장 형식(MP4, 1080p 이하, 512MB 이하)에 맞습니다.

## 어떻게 녹화하나

화면을 실시간으로 녹화하면 무거운 장면에서 프레임이 떨어집니다. 그래서 페이지의 시간을 가상 시계로 바꿔, **한 프레임(1/30초)씩 흘리고 → 그리고 → 캡처**합니다. 캡처가 느려도 영상은 정확히 30fps로 매끄럽습니다.

| 파일 | 하는 일 |
|---|---|
| `clock.js` | 페이지보다 먼저 주입하는 가상 시계. `requestAnimationFrame`·`performance.now`·`Date.now`·`setTimeout`·`setInterval`을 `__promo.step(ms)`로만 흐르게 한다 |
| `director.js` | 연출. 장면마다 카메라(궤도·추격), 환경(계절·시간대·날씨), UI 보이기, 자막(큰 문구·이름표·알약)을 시간의 함수로 정한다. 컷 사이에는 시뮬레이션을 앞당겨(`seek`) 원하는 순간(이륙 등)으로 간다 |
| `record.mjs` | ego-browser로 실행하는 녹화기. 1.5배 해상도(2880×1620)로 그려 1080p로 줄이며 장면마다 ffmpeg로 바로 인코딩한다(프레임을 디스크에 쌓지 않음) |
| `music.py` | 배경음 합성(96BPM, Am9 → Fmaj7 → Cmaj9 → G6). 장면 구간에 맞춰 베이스·킥·하이햇·아르페지오가 들어오고 제목·엔딩에 라이저와 충격음 |
| `build.sh` | 장면 영상 이어 붙이기, 음악 입히기, 줄임본·포스터 만들기 |
| `config.json` | 녹화 설정(`mode`: `preview`/`full`, `scenes`, `dsf`, `out`) |

```bash
npm run dev                                   # 개발 서버(5188)
python3 promo/music.py promo/out/music-dry.wav full
python3 promo/music.py promo/out/music-teaser-dry.wav teaser
# (마스터링) ffmpeg -i music-dry.wav -af "lowpass=f=9500,aecho=0.8:0.55:90|170|260:0.22|0.16|0.1,loudnorm=I=-17:TP=-1.5:LRA=11" music.wav
ego-browser nodejs < promo/record.mjs         # config.json의 mode가 full이면 약 25분
sh promo/build.sh
```

- `record.mjs` 맨 위 `ROOT`가 이 폴더의 절대 경로여야 합니다(ego-browser 스크립트는 작업 폴더가 `/`). `config.json`의 `out`은 `ROOT` 기준 상대 경로도 됩니다.
- 구도만 볼 때는 `config.json`을 `{"mode": "preview", "out": "out/preview/"}`로 두면 장면마다 몇 장만 저장합니다(전체 약 4분).
- 특정 장면만 다시 찍으려면 `"scenes": [9]`처럼 지정합니다. 장면마다 준비 단계에서 시뮬레이션을 앞당기므로 순서와 상관없이 다시 찍을 수 있습니다.

## 주의

- 녹화할 때마다 새 브라우저 공간을 엽니다. 같은 페이지에 가상 시계가 두 번 주입되면 버튼 클릭이 먹지 않습니다.
- 가상 시계 모드에서는 페이지 안 `setTimeout`도 `step`할 때만 흐릅니다. 녹화기 밖에서 `page.evaluate`로 기다리는 코드를 넣으면 멈춥니다.
- 버튼 누르기처럼 한 번만 해야 하는 일은 `once(t, a)`로 한 프레임에만 실행합니다(두 프레임에 걸리면 창이 열렸다 닫힙니다).
- 2배 해상도(3840×2160)는 렌더러가 메모리 부족으로 멈춰 1.5배를 씁니다.
- AI 장면은 실제 AI API를 부릅니다(서버 `.env.local` 키, 수십 회 호출).
- 브랜드·사람·화물 정보는 모두 가상입니다. 배경음은 코드로 합성해 저작권 문제가 없습니다.
